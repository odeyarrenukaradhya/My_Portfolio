# Renukaradhya Odeyar — Personal Portfolio & Resume Website

A modern, interactive brutalist-styled developer & designer portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## 🚀 Features

- **Interactive Brutalist UI**: Electric lime accents, custom cursor tracking, pill navigation, and micro-interactions.
- **Project Showcase**: Detailed case studies for ShareX (File Sharing Platform), Gradium (Career Development Platform), and UI/UX design work.
- **Embedded Resume Viewer**: Built-in resume viewer modal and direct PDF download option for `RENUKARADHYA ODEYAR C G`.
- **Responsive Design**: Optimized layout across mobile, tablet, and desktop screens.
- **Contact & Social Integrations**: Quick links to LinkedIn, GitHub, Instagram, Behance, and Dribbble.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 6
- **Styling**: Tailwind CSS, Vanilla CSS
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React, React Icons

## 📦 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18+) and **npm** installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/odeyarrenukaradhya/YOUR_REPOSITORY_NAME.git
   cd My_Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
